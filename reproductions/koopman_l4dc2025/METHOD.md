# Koopman 生成元与 GHJB 策略迭代

这是 Zeng–Zhou–Meng–Liu，L4DC 2025 的原创 MATLAB 方法级复现：从采样轨迹辨识 Yosida 生成元、恢复非线性控制仿射模型，再用随机特征解 GHJB、改进策略，最后在真实摆模型上冻结评估。没有移植作者源代码。当前实现不宣称复现 Table 3 或原图的精确数值。

论文：[正式版](https://proceedings.mlr.press/v283/zeng25a.html)，[含证明预印本 v1](https://arxiv.org/abs/2412.01085v1)。版本和 PDF 哈希见 `sources.json`；逐页阅读与公式映射见 `../../docs/fulltext/koopman_l4dc2025.md`。

## 直接运行

在此目录中：

```matlab
[result, runDir] = demo_koopman;
tests = runtests('test_koopman.m');
assert(all([tests.Passed]));
```

默认运行保存到唯一的 `results/run-...` 目录，含原始轨迹、完整生成元、随机特征参数、各轮求解权重/奇异值、训练/留出/评估初值、50条真实闭环轨迹、配置、指标、图和源码哈希。数据不来自缓存；同名运行拒绝覆盖。数值程序只需基础 MATLAB，源码哈希使用标准 JVM。源码以少量有具体职责的函数组织，不依赖本仓库的旧 LQ 基线。

## 算法与知识边界

系统为确定性 CT ODE，完全观测、单输入、无限时域无折扣调节，代价 `x'Qx+R*u^2` 无半因子。辨识器仅接收 `data.t/data.x/data.u` 及字典/求积配置，不接收 f、g、状态导数、A/B 或真实物理参数。原始轨迹由仿真器产生；每条辨识轨迹的 u 恒定，满足论文扩展系统 `udot=0`。这与控制评估时的连续反馈不同。

1. 对 `[x1,x2,u]` 使用 `x1^p1*x2^p2*u^q`，`p1,p2=0:5`，`q=0,1`，剔除常数，共 71 维，保留状态-输入耦合。
2. 对每个字典函数实施有限时域 Yosida 算子 `lambda^2*int(exp(-lambda*t)*phi(flow(t))) - lambda*phi0`，由离散样本插值和求积形成全部生成元右端。没有使用有限差分状态导数或真模型拟合目标。
3. 采用等价的“先减 phi0 再积分”写法降低大 lambda 的相消，并保留有限时域尾项；不是偷偷去掉 Yosida 偏差。每段使用四点局部三次插值、16点 Gauss–Legendre 对指数权重求积。lambda=1000 时有效信息集中在初始几帧，精度因此依赖插值假设；它不产生传感器没有测到的新信息。
4. 对缩放后的字典做 SVD，秩不足失败。用生成元中对应 x1/x2 的列恢复 fhat、ghat。
5. 给定 K0，用 GHJB 线性最小二乘估计价值函数，随后 `u=-0.5/R*ghat'*grad(V)`。随机特征固定，只拟合输出层；报告截断奇异值和残差。
6. 单独运行相同特征/同一PI预算的 truth-model PI 作为参照。参照模块明确标识 `oracle_pendulum`，只有这次调用允许真实 f/g；参照值并非解析最优解。
7. 50 组相同初值在真实摆上比较初始策略、数据模型策略和 truth-model PI。RK4 每个子步重新求反馈，未做 ZOH 或饱和；评估期间不学习，保存四个一致的输入通道。

最后一轮 beta 对应前一策略的评估，新贪心策略独立保存；不会把新策略和旧价值系数称作严格一致配对。默认运行最后策略变化极小仍仅属数值观察。

## 原文与本实现的差别

| 项目 | 原文明确给出 | 本实现 |
|---|---|---|
| 2D 对象 | inverted pendulum，未给方程/参数 | `x1dot=x2; x2dot=sin(x1)-x2+u`，规范化重力/长度/输入增益均为1、阻尼1，均为本实现补充 |
| 辨识初值/输入域 | [-1,1]^3 | 相同，均匀随机，seed=20250907；全轨迹不保证留在初始域 |
| 数据量与采样 | 1000初值，1秒，100Hz | 相同；仿真 RK4 内步0.001秒 |
| 字典 | 每个状态阶数≤5，输入总次数≤1，无常数 | 相同，71列 |
| Yosida lambda / 求积 | 未给具体数值/离散规则 | lambda=1000，局部三次插值+指数加权 Gauss 求积；另外测试20/100/1000 |
| Q/R、初始稳定策略 | 未给具体值 | Q=I,R=1,K0=[4,3]；这是额外的预先稳定策略知识 |
| GHJB 网络 | 200个 tanh 随机隐单元，3000点 | 共200特征：3个二次项+197个减去零点值/线性项的 tanh；确保 V(0)=gradV(0)=0，属于明确的特征修改 |
| 特征分布、正则化 | 未给 | W=1.5*N(0,1)，b均匀[-1,1]，SVD相对截断1e-10 |
| PI轮数 | 正文未明示；预印本图文件名含 iter_10 | 10轮固定预算，额外检查K0=[5,4]/12轮 |
| 评估 | 50条、10秒、相同成本比较 | 相同规模；RK4步长0.005秒，另用独立ode45检查 |
| 原对照 | resolvent、logarithm、lifted-linear、ADP及四种维数 | 当前只实现resolvent控制仿射链及truth-model PI；未实现其它对照和4D/6D/9D |

不能仅因误差比论文表小就宣称复现成功：物理模型、lambda、特征、随机样本和评价指标可能不同。论文2D Table3给 Ef=3.7e-3、Eg=9.9e-3；本实现值只作为当前规范化模型的独立检验。

## 测试与限制

`test_koopman.m` 检查：独立留出 f/g 与闭环成本；锚定特征的有限差分梯度；具有解析矩阵指数流的有限时域 Yosida 算子；真正状态-输入耦合的精确流；秩/NaN/错误输入执行标记拒绝；ode45 对 RK4；仿真真值字段不进入辨识器；lambda 和初始K/迭代预算敏感性。

这些是方法实现与数值调试证据。未完成全域稳定/ROA、一般未知摆适用性、噪声鲁棒性、有限采样误差界或硬件验证；无穷时域最优代价也没有被10秒仿真证明。论文定理的附加正则性和统一尾项问题见全文笔记。
