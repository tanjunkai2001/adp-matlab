# Experiment protocol

Specify before running a comparison:

1. Scientific question, methods and ablations.
2. Plant, learner knowledge, cost, state/input constraints, execution timing.
3. Training/evaluation split, seeds, initial states, disturbances and parameter uncertainty.
4. Hyperparameter search range and equal comparison budget.
5. Metrics, success/failure thresholds, numerical tolerances and stopping rules.
6. Every expected run and missing/failed-run reporting.
7. Raw trajectories and source/config/environment manifest.
8. Figure reconstruction from saved results, including full-data metrics and display-only subsampling.
9. Conclusions justified by these finite experiments, and separately untested claims.
