# ADR 0002：以数学能力描述方法，保留可选后端

状态：采纳设计；公共库保留CT积分PI参考实现，另有七篇方法独立实现，具体状态以registry/reproductions.json为准。日期：2026-09-07。

近年全文显示，不同ADP相关方法在随机过程、目标、学习对象、初始化与数据算子上差异显著。用“所有方法都是actor–critic”或单个“stochastic”开关无法表达这些区别。

采用可组合的数学能力登记，并保留专门的实现入口。核心首先处理模型知识、数据、学习/执行时间线、数值诊断和运行证据；PDE、Koopman、风险分布、MPC与Simulink按需求接入。不建立强制通用critic，不生成仅转发参数的空类。

每个新方法先填写 method-intake 与公式映射，取得最小独立数值对照后才标记 implemented/numerically_validated。研究论文、算法家族、软件模块三者使用不同登记，不以论文数量表示代码能力。
