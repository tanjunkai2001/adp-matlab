This existing procedure pools batches under a common probe and fits at 100, 400, 1,000 and 4,000 paths. A small-sample fit may stop it before 4,000. Exact replay of the historical numbers still needs the archived configuration and data; see the run guide.

Precision procedure: 40 × 100 paths
addpath(fullfile(pwd, ...
    'reproductions','meanfield_lqg2025'));
runId = char(datetime('now', ...
    'Format','yyyyMMdd-HHmmss-SSS'));
outputDir = fullfile(pwd,'runs', ...
    ['meanfield-precision-' runId]);
precision = mf_precision_check( ...
    outputDir,mf_config(),40);

Getting started

Your first run
in MATLAB.

Download the v0.5.0 source or clone the GitHub repository. Open its root folder in MATLAB and run the commands alongside.

The baseline uses base MATLAB with the standard JVM. Expect a learned gain close to [1, √3].
