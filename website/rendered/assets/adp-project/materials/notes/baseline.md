# 新方法接入：必须写清的数学契约

版本 0.2；2026-09-07。本文件规定未来扩展的接口含义，不代表列出的算子已经实现。当前可调用接口仍以 [IMPLEMENTED_API.md](https://github.com/tanjunkai2001/adp-matlab/blob/v0.5.0/docs/IMPLEMENTED_API.md) 为准。

## 1. 一个算法名不足以确定实现

每个方法应填写以下信息。用不到的项写 `not_applicable`；未知条件写 `unknown`，不能用默认值掩盖。

| 维度 | 必须登记的内容 | 为什么影响代码 |
|---|---|---|
| 系统/时间 | CT ODE、CT Itô diffusion、CTMC、DT transition、hybrid；状态与观测 | 导数、Hessian、跳跃率和一步转移对应不同Bellman算子 |
| 目标 | 有限时域、无限时域折扣、无折扣调节、长期平均；reward或cost及正负号 | 决定终端条件、折扣率、偏置归一化和策略改进方向 |
| 学习对象 | V、Q、连续时间q/advantage、actor-only、model-plus-value、分布 | 不能要求每种方法都返回critic权重 |
| 策略评估 | 精确/近似PI、VI、部分评估/GPI、LSTDQ、Bellman residual minimization、Bellman inequality | 即使都用最小二乘，方程和固定点也可能不同 |
| 初始条件 | 预先可容许策略、模型给定稳定器、数据驱动稳定化、homotopy/damping、有限时域初始化 | 不知道初始稳定策略时不能静默套用本例K0 |
| 数据 | on/off-policy、reset/单轨迹、状态/输出、轨迹窗口/一步样本、离线/在线 | 决定回归式、校正项、过滤器、数据依赖及可辨识条件 |
| 知识 | f、g、扩散、扰动、系统阶数、噪声界、观测映射中哪些已知 | “model-free”标签不能代替逐项声明 |
| 数值 | 特征尺度、SVD/QR、截断与正则化、求积、优化/PDE残差 | 数值误差会传递到策略和证书 |
| 证书 | 确定性稳定、均方稳定、概率安全、实用邻域、有限样本置信界 | 检查器必须与结论类型一致 |
| 执行 | 连续反馈/ZOH、事件、过滤、网络、执行器、更新顺序 | 使用实际输入仍不自动满足目标策略的学习恒等式 |

方法注册表是设计约束；算法是否可运行只看 `status`、入口和对应运行证据。

## 2. 不再统一塞入“随机ADP”

物理过程噪声的 Itô 模型为

```text
dx = b(x,u) dt + Sigma(x,u) dW
L^u V = gradV' b + 0.5 trace(Sigma Sigma' HessV)
```

其价值求解要支持 Hessian；随机线性系统的均方稳定通常检查二阶矩/Lyapunov算子，单看漂移矩阵 Hurwitz 不足。SDE离散化阶次、随机流和期望估计误差必须另记。

有限状态 CTMC 则使用生成率矩阵：`L^u V(s)=sum_j q(s,j,u)*V(j)`，并满足率矩阵约束。它不需要把连续机械系统状态加入“高斯噪声开关”。人工 vanishing-viscosity 项属于PDE正则化，也不是物理扩散模型。

进一步分开三类分布：不确定模型参数的分布、随机回报的分布、探索策略的动作分布。风险敏感指数效用、CVaR、熵正则化、分布鲁棒歧义集并不等价。平均成本模型还需保存 average cost 与 bias 的归一化条件。

## 3. 数据与数值积分

每批积分数据最少说明：`integralSource`、`quadratureRule`、实际采样时刻、窗口端点、目标/行为策略身份、执行输入、已知或未知的 `integrationErrorBound`、数据质量诊断。

当前参考例的积分来自 ODE 增广成本状态；误差界字段为空，意为未提供经证明上界。稀疏传感器成本应通过独立求积接口产生，不能沿用参考例残差精度。未来 Bayesian quadrature 还需记录核、尺度、超参数训练数据、后验方差与误差界的解释，不能把方差直接当标准差。

回归同时保存有效秩、奇异值、尺度变换、条件数、秩容差与正则化。回归残差小可能来自近奇异数据或过拟合，不代表策略近优。LSTDQ求固定点与直接最小化Bellman残差不得共用一个未注明语义的 `leastSquares` 方法。

有限样本分析额外保存 `batch_reuse_policy` 和 `cross_iteration_sample_dependence`：每轮重新采样、固定批次复用、replay分别说明；一次新批次定理不能自动覆盖固定数据重复迭代。区分同轨迹时间相关、跨迭代依赖和所需混合条件。

输出反馈方法另外保存过滤器状态、初值、瞬态舍弃区间、窗口/提升维数，以及可观测性和数据秩条件。不得用真实状态替换输出数据后仍沿用原信息假设。

## 4. 策略初始化与actor-only方法

未来 `initialization` 模块输出候选策略、稳定性检查对象、有效域、所用模型知识及是否允许收集数据；输出失败时不继续PI。Homotopy/damping方法需要保存每次缩放参数、稳定化阶段停止条件和转回原系统的条件。“不要求用户提供稳定策略”不等于“可以对任意不稳定对象安全采样”。

Actor-only/critic-free方法可以只返回策略参数和直接回归诊断。值函数可以作为独立评估器的产物，但不能伪造算法内部critic。注册表中的方法结构应决定输出类型，而不是所有算法继承同一份actor–critic状态。

## 5. 表示学习与PDE后端

Koopman模块分别声明字典、生成元/一步算子、线性/双线性动态、状态重构映射和误差界。字典用于模型辨识和特征用于价值估计是两份对象。保存学到的特征版本，明确在策略迭代期间冻结还是继续训练；重训特征后旧回归数据须重新构造。

PINN/HJB后端必须保存时间导数、终端/边界条件、定义域、collocation分布与边界损失。稳态HJB可能有多个解；不能只看训练损失。有限时域向无限时域扩展同时跟踪截断误差、函数逼近误差及新一轮求解误差。价值误差、梯度误差与策略误差分别检验。

Epigraph安全HJB增加成本坐标和变分不等式。Conformal/场景校准保存训练/选择/校准/测试的分工、抽样分布、样本量、置信度、允许违例和阈值选择方式；不把样本安全率写成全域确定性保证。

MPC/rollout仅作为可选规划后端：记录预测模型、终端价值/集合、规划时域、求解预算和可行性处理。一次规划成功不能替代递归可行性分析。

## 6. 最小验收算例随数学类型变化

| 类型 | 首个可独立交叉检查的算例 | 必须包含的反例/检查 |
|---|---|---|
| CT/DT LQ PI/VI/Q | CARE/DARE或可手算解，与相同成本比较 | 错误符号、折扣、初始策略、秩不足 |
| 输出反馈 | 同一线性系统的状态反馈与输出反馈对照 | 过滤器初值、不可观测系统、秩不足 |
| Itô LQ | 小维度广义Riccati/二阶矩方程 | 漂移稳定但均方不稳定、独立种子期望估计 |
| 平均成本/风险目标 | 可解析有限状态MDP或随机LQ | bias平移、风险参数趋零、不同目标不可直接同表比较 |
| Critic-free | 与相同问题的值函数PI比策略/成本 | actor回归秩、消元误差、值函数只作外部参照 |
| Koopman/学特征 | 可精确提升的小系统，再加失配 | 双线性项遗漏、字典线性相关、训练外检验 |
| HJB/PINN | 有限时域LQ/Riccati时间方程 | 终端边界、非稳定解分支、梯度误差 |
| 安全/鲁棒 | 小维度已知可行域及不可行状态 | 求解失败、实际输入偏差、分布外状态 |

这些是后续方法的验收要求，未实现方法不会作为“跳过的通过测试”计入当前测试数量。
